# TTP223B Capacitive Touch Sensor with Arduino UNO
![TTP223B Capacitive Touch Sensor with Arduino UNO](https://playwithcircuit.com/wp-content/uploads/2024/04/Interfacing-TTP223-Touch-Sensor-with-Arduino.jpg)

A simple Arduino project demonstrating how to interface a TTP223B capacitive touch sensor with an Arduino UNO and use the sensor's digital output to detect a human touch.

## Overview

The TTP223B is a single-channel capacitive touch sensor module based on the TTP223-BA6 touch-sensing IC. It provides a simple way to add touch-based input to Arduino and other microcontroller projects without using a conventional mechanical push button.

The module operates by detecting changes in capacitance when a finger approaches or touches its sensing electrode. The TTP223-BA6 processes this change internally and provides a digital output indicating the detected touch condition.

The sensor can operate from 2.0 V to 5.5 V and has very low power consumption. With a 3 V supply in low-power mode, its typical operating current is approximately 1.5 µA, with a maximum of 3.0 µA.

This project uses an Arduino UNO to read the digital output of the TTP223B. An external LED can be controlled based on the detected touch, providing a simple visual indication of the sensor output.

## Features

- Single-channel capacitive touch sensing
- Operating voltage: 2.0 V to 5.5 V
- Very low power consumption
- Digital CMOS output
- Direct and toggle operating modes
- Active-HIGH or active-LOW output configuration
- Adjustable sensitivity using an external capacitor
- Automatic calibration
- Four M2 mounting holes on the module
- Suitable as an alternative to a traditional touch switch

## How Capacitive Touch Sensing Works?

The TTP223B uses capacitive sensing to detect a human touch. The sensing electrode has a certain capacitance under normal conditions. When a finger approaches or touches the electrode, the capacitance of the system changes.

The sensing electrode is connected to the input of the TTP223-BA6 IC. The IC continuously monitors the sensing condition and detects changes using its internal oscillator and sensing circuitry.

Once a valid touch is detected, the internal control logic processes the event and changes the state of the digital output. The output behavior depends on how the IC has been configured.

This means that the Arduino does not need to perform capacitance measurements itself. It only needs to read the digital signal generated by the TTP223B.

## TTP223-BA6 Pinout
![TTP223B Capacitive Touch Sensor Pinout](https://playwithcircuit.com/wp-content/uploads/2024/04/Pin-Diagram-of-TTP223-BA6-IC.jpg)
The TTP223-BA6 IC provides dedicated pins for power, sensing, output, and configuration.

| Pin | Function |
|---|---|
| Q | Digital output |
| VSS | Ground |
| I | Capacitive sensing input |
| AHLB | Output polarity selection |
| VDD | Supply voltage |
| TOG | Direct/toggle mode selection |

The **Q pin** provides the digital output of the touch IC.

The **VSS pin** is connected to ground, while the **VDD pin** provides the supply voltage. The IC supports a supply range of approximately 2.0 V to 5.5 V.

The **I pin** is the capacitive sensing input and is connected to the sensing electrode.

The **AHLB pin** determines the output polarity. When AHLB is LOW, the output is active HIGH. When AHLB is HIGH, the output becomes active LOW.

The **TOG pin** determines the operating mode. A LOW level selects direct mode, while a HIGH level selects toggle mode.

## Operating Modes

The TTP223-BA6 supports four operating configurations based on the states of the TOG and AHLB pins.

| TOG | AHLB | Operating Mode |
|---|---|---|
| LOW  | LOW  | Direct mode, active HIGH |
| LOW  | HIGH | Direct mode, active LOW |
| HIGH | LOW  | Toggle mode, power-on state LOW |
| HIGH | HIGH | Toggle mode, power-on state HIGH |

### Direct Mode

In direct mode, the output responds to the detected touch condition. With active-HIGH configuration, the output changes from LOW to HIGH when a touch is detected.

When the touch is removed, the output returns to its inactive state.

### Toggle Mode

In toggle mode, every detected touch changes the output state.

For example, if the output initially starts LOW, the first touch changes it to HIGH. The next touch changes it back to LOW. Each subsequent touch continues to alternate the output.

This makes toggle mode useful when the sensor needs to behave like an ON/OFF push button.

## TTP223B Module Pinout

![TTP223B Capacitive Touch Sensor Pinout](https://playwithcircuit.com/wp-content/uploads/2024/04/Pinout-of-TTP223B-touch-Sensor.jpg)

The commonly available TTP223B module provides three primary connections:

| Module Pin | Description |
|---|---|
| VDD | Positive supply |
| SIG | Digital signal output |
| GND | Ground |

The **VDD** pin supplies power to the module. For an Arduino UNO setup, it can be connected to the 5 V supply.

The **GND** pin should be connected to the Arduino ground.

The **SIG** pin provides the digital output from the touch sensor and is connected to an Arduino digital input.

In the default active-HIGH configuration used by the module, the Signal output becomes HIGH when a touch is detected.

## Hardware

The TTP223B module contains the TTP223-BA6 IC, the capacitive sensing electrode, configuration components, and an indicator LED.

The circular conductive area on the module is the touch-sensitive electrode. When a finger touches this area, the capacitance changes and the TTP223-BA6 detects the event.

The module also includes a power indicator LED that turns ON when power is applied.

The sensitivity of the touch input can be adjusted using an external capacitor. The supported adjustment range is approximately 0 to 50 pF.

## Internal Circuit Configuration

The exact circuit can vary between different TTP223B module versions. In the TTP223B V1.0 module used for this project, the TOG and AHLB pins are pulled to ground through 1 kΩ resistors.

This configuration places the sensor in direct mode with an active-HIGH output.

The Q output of the TTP223-BA6 is connected to the module's Signal pin. The VSS pin is connected to ground, while I sensing input is connected to the capacitive electrode.

The sensing input is also connected to an external capacitor, with the other side of the capacitor connected to ground.

The VDD pin is connected to the supply voltage. The module's power indicator LED is connected to the supply through a series resistor.

## Arduino UNO Interface

The TTP223B can be connected directly to an Arduino UNO because its output is already a digital signal.

For this project, connect the module's VDD pin to the Arduino UNO 5 V pin and connect GND to Arduino GND.

Connect the TTP223B SIG pin to Arduino digital pin 2. This pin is used to monitor the touch sensor output.

An external red LED can be connected to Arduino digital pin 4 through a 100 Ω resistor. The other terminal of the LED is connected to GND.

### Wiring

| TTP223B / LED | Arduino UNO |
|---|---|
| VDD | 5 V |
| GND | GND |
| SIG | Digital Pin 2 |
| LED anode through 100 Ω resistor | Digital Pin 4 |
| LED cathode | GND |

## How the Project Works

When power is applied, the TTP223B continuously monitors its capacitive sensing electrode.

When a finger touches the electrode, the capacitance changes. The TTP223-BA6 detects this change and generates a digital output signal.

The Signal output of the module is connected to Arduino digital pin 2. The Arduino reads this signal and can use it to control another output.

In this project, digital pin 4 is used to control an external LED. When the Arduino detects the HIGH output generated by the touch sensor, the LED can be turned ON. When the touch condition is removed, the output returns to its inactive state and the LED can be turned OFF.

The same digital signal can also be used to control other devices such as relays, buzzers, motors, or additional digital logic.

## Design Considerations

Capacitive touch detection is affected by the physical construction of the sensing area. Factors such as electrode size, surrounding conductive objects, PCB layout, enclosure material, and the distance between the finger and electrode can influence the sensor response.

For prototyping, the sensing electrode already present on the TTP223B module provides a convenient solution. For a custom hardware design, the sensing electrode can instead be incorporated directly into the PCB.

The external sensitivity capacitor can also be considered when adapting the sensor for a different electrode arrangement or physical enclosure.

## Conclusion

The TTP223B provides a straightforward way to add capacitive touch functionality to an Arduino project. The TTP223-BA6 handles the sensing and touch detection internally, while its digital output allows a microcontroller to respond to the detected event without requiring additional capacitive-sensing circuitry.

With its low operating current, 2.0 V to 5.5 V supply range, direct and toggle modes, and configurable output polarity, the TTP223B can be adapted to a variety of touch-control applications.

For the Arduino UNO interface described here, the sensor is powered from the Arduino, its SIG output is connected to digital pin 2, and an external LED is controlled through digital pin 4 using a 100 Ω resistor.
